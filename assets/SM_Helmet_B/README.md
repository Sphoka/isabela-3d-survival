# SM_Helmet_B

Warm champagne-silver weathered astronaut helmet with top carry-handle, circular side ear-hubs, stepped neck ring, and reflective curved glass visor.

## Specifications
- **Polycount**: 11202 tris (LOD0; Godot 4.7.2 auto-LOD enabled on import)
- **Scale**: Real-world meters (~0.30m height), Y-up glTF 2.0 (`.glb`), pivot at base (`Z = 0` at bottom of neck ring)
- **Materials**:
  - `M_Helmet_Shell_B` (metallic weathered shell, handle, ear-pods, neck ring)
  - `M_Helmet_Visor_B` (separate curved glass visor material)
- **Textures (2048x2048)**:
  - `T_Helmet_B_BaseColor.png` (sRGB)
  - `T_Helmet_B_Normal.png` (OpenGL Y+, Non-Color)
  - `T_Helmet_B_ORM.png` (Packed: R = Occlusion, G = Roughness, B = Metallic, Non-Color)
