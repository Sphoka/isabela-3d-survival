# SM_Helmet_A

Brushed weathered silver-grey astronaut helmet with top carry-handle, circular side ear-pods, and dark smoked visor.

## Specifications
- **Polycount**: 11094 tris (LOD0; Godot 4.7.2 auto-LOD enabled on import)
- **Scale**: Real-world meters (~0.30m height), Y-up glTF 2.0 (`.glb`), pivot at base (`Z = 0` at bottom of neck ring)
- **Materials**:
  - `M_Helmet_Shell_A` (metallic weathered shell, handle, ear-pods, neck ring)
  - `M_Helmet_Visor_A` (separate curved glass visor material)
- **Textures (2048x2048)**:
  - `T_Helmet_A_BaseColor.png` (sRGB)
  - `T_Helmet_A_Normal.png` (OpenGL Y+, Non-Color)
  - `T_Helmet_A_ORM.png` (Packed: R = Occlusion, G = Roughness, B = Metallic, Non-Color)
